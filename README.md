# 🛒 홈쇼핑 프로모션 시뮬레이터 + AI 에이전트

> LOTTE AX Challenge 2026 · 롯데홈쇼핑 과제 「프로모션 시뮬레이터」 예선 데모

카드 청구할인·무이자 할부·사은품 조건을 바꿔 가며 **방송 전에** 주문·매출·**공헌이익**을 시뮬레이션하고,
MD·방송기획자가 자연어로 질문하면 AI 에이전트가 시뮬레이터를 도구로 호출해 근거와 함께 추천합니다.

## 해결하려는 문제
| 지금 (가정) | 바꾸려는 모습 |
|---|---|
| 프로모션 조건을 경험·관행으로 결정 | 과거 데이터 기반으로 조건별 결과를 미리 비교 |
| 매출(주문) 중심 평가 | 할인 부담(카드사 분담)·무이자 수수료·사은품 원가(협력사 분담)·반품까지 반영한 **이익** 중심 평가 |
| 비교 자료를 엑셀로 수작업 작성 | 질문 한 줄 → 비교표·추천·회의용 리포트 자동 생성 |

## 주요 기능
1. **시나리오 비교** — 같은 방송(상품·요일·시간)에서 프로모션 A/B/C의 주문·순매출·공헌이익과 80% 예측 범위 비교
2. **최적 조합 찾기** — 125개 조합(카드할인 5 × 무이자 5 × 사은품 5) 전수 시뮬레이션, 이익/매출 목표·비용 상한 설정
3. **AI 에이전트** — OpenAI Responses API 도구 호출. 숫자는 모두 시뮬레이터 결과에서만 인용 (도구 호출 기록 공개)
4. **회의용 리포트 자동 생성** — 핵심 메시지(이익 감소 경고, 반품률 상승 등) + 비교표를 마크다운으로 출력
5. **모델 신뢰도 공개** — 미래 기간 예측 오차, 예측 범위 적중률, 프로모션 효과 추정 정확도

## 구조
```
data_gen.py   합성 방송 데이터 생성 (정답 효과를 알고 있는 데이터)
model.py      LightGBM 주문 수 모델(단조 제약) + 반품률 모델 + 검증
simulator.py  조건별 주문 → 매출 → 비용 → 공헌이익 계산, 비교·최적화
agent.py      LLM 에이전트 (search_products / get_product_history / simulate_promotions / optimize_promotion)
report.py     규칙 기반 핵심 메시지 + 리포트 생성
app.py        Streamlit 데모 화면
```

```
사용자 질문 ─▶ AI 에이전트(LLM) ─▶ 도구 호출 ─▶ 시뮬레이터 ─▶ 예측 모델(주문·반품)
                    ▲                                   │
                    └──── 결과(JSON) ◀── 이익 계산 ◀────┘
                    └─▶ 결론 · 비교표 · 근거 · 리스크 · 다음 액션
```

## 검증 결과 (합성 데이터)
| 지표 | 값 | 의미 |
|---|---|---|
| 미래 기간 주문 예측 오차(WAPE) | 22.3% | 2026-06 이후 방송 1,708건, 학습에 사용 안 함 |
| 80% 예측 범위 적중률 | 80.3% | 범위가 과장·과소되지 않음 |
| 프로모션 효과 추정 오차 | 평균 6.0%p | 카테고리×프로모션 15개 조합에서 정답 효과와 비교 |

- **단순 평균 비교의 함정**: 가전 카드할인 방송은 미할인 방송보다 주문이 59% 많지만, 할인이 황금시간대·고가 상품에 몰린 효과가 섞인 값. 모델은 시간대·상품을 함께 고려해 프로모션 자체의 효과를 분리
- **한계**: 데이터가 적은 조합에서 효과를 보수적으로(작게) 추정하는 경향 → 실제 데이터에서는 A/B 테스트 방송으로 보정 필요

## 실행
```bash
pip install -r requirements.txt
python src/data_gen.py     # 합성 데이터 생성
python src/model.py        # 모델 학습·검증
streamlit run app.py       # 데모 실행 (AI 에이전트 탭은 OPENAI_API_KEY 필요)
```

## 본선(실제 데이터) 적용 계획
- `data_gen.py`를 실제 방송·주문·프로모션 데이터 로더로 교체 → 같은 컬럼 구조로 맞추면 나머지는 그대로 동작
- 실제 데이터의 추가 변수(쇼호스트, 방송 분량, 재고, 경쟁 채널 편성, 날씨 등) 반영
- 카드사·협력사 분담률, 무이자 수수료, 사은품 원가 등 계산 가정을 현업 값으로 교체

> ⚠️ 이 데모는 공개 정보를 바탕으로 만든 **합성(가상) 데이터**를 사용합니다. 실제 롯데홈쇼핑 데이터·수치가 아닙니다.
